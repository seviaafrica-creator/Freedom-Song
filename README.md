# Let Freedom Be Our Legacy

An anthem for human rights activists. Original lyrics, original music —
nothing sampled or adapted from any existing song.

**Listen and share:** this repository hosts the song's public page —
it is served live at:

**https://seviaafrica-creator.github.io/let-freedom-be-our-legacy/**

- `index.html` — the public share page (player, download, lyrics)
- `audio/freedom-song-take12-final.mp3` — the master recording (2:36)
- `lyrics-take12.txt` — the final lyric sheet

The arrangement: one voice alone, then bass guitar, then piano, then drums
and dondo (talking drum), then the entire band — one voice becoming a crowd.
